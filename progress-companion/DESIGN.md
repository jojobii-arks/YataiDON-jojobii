# Cursor theme (companion)

Source: https://getdesign.md/cursor/design-md

Tokens live in `themes/cursor.css` and are applied via `data-theme="cursor"`.
Swap themes by adding another CSS file under `themes/` and registering it in
`src/lib/theme.ts`.
